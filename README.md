# 🔢 Binary Number System: Arithmetic & Root Functions

This project implements a **custom binary-like number system** in R and builds arithmetic and root operations from the ground up. The goal is to demonstrate how numeric systems and operations can be represented **programmatically**, without relying on built-in arithmetic, using object-oriented concepts and functional decomposition in R.

---

## 📌 Project Overview

- **Language:** R  
- **Focus:** Custom numeric representation + arithmetic logic  
- **Core Idea:**  
  Represent numbers as structured objects (`pqnumber`) and implement arithmetic rules manually, including sign handling, digit-wise operations, and validation.

This project emphasizes:
- Low-level numerical reasoning  
- Clean function design  
- Defensive programming (input validation)  

---

## 🧠 Concepts Implemented

- Custom number class (`pqnumber`)
- Digit-wise arithmetic logic
- Sign-aware operations
- Manual carry / borrow handling
- Root computation using iterative logic
- Functional decomposition and reuse
